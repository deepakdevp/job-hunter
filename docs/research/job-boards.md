# Job Boards Registry

## Target Roles

### Standard
- Software Engineer
- Full Stack Developer / Engineer
- Frontend Engineer
- Backend Engineer
- AI Engineer
- Agentic AI Engineer

### AI-Era Roles (2025-2026)
- AI Agent Engineer — builds autonomous AI agents (LangChain, LlamaIndex, CrewAI)
- Agent Orchestration Engineer — multi-agent workflow architecture
- AgentOps Engineer — SRE for AI agents, monitoring/retraining fleets
- Context Engineer — information architecture for LLM calls (RAG, memory, prompts)
- LLM Integration Engineer / GenAI Integration Engineer — integrates LLM APIs into products
- AI Product Engineer — hybrid product-engineer for AI features
- AI Reliability Engineer (AI SRE) — production LLM system reliability
- LLM Platform Engineer — internal platform for LLM deployment
- MCP Server / AI Tooling Developer — Model Context Protocol integrations
- Creative Technologist (AI) — generative AI + creative applications (in demand in Japan)
- AI Innovation Lead — technical leadership for AI adoption

### Top 5 Emerging Roles (Example Profile)
1. AI Agent Engineer (direct fit for agentic AI experience)
2. Context Engineer (RAG expertise)
3. AI Product Engineer (full-stack + LLM)
4. MCP Server / AI Tooling Developer (MCP experience)
5. Creative Technologist AI (generative AI + full-stack)
